# ROSE - A Magical Bloom Animation

## Overview

ROSE is a Python-based animated flower project developed using Pygame. It illustrates the growth of a rose from a small bud into a fully bloomed flower through smooth animations and visual effects.

The project combines creative programming, animation techniques, and graphical design to create an interactive blooming experience.

## Features

- Animated rose growth from a small bud.
- Gradual blooming with multiple layers of petals.
- Starry night background with twinkling stars.
- Animated green stem and leaves.
- Gentle wind movement.
- Magical glowing effects around the flower.
- Floating golden particles.
- Interactive animation restart using the SPACE key.

## Technologies Used

- Python
- Pygame
- Math
- Random

## Installation

### 1. Clone the Repository

```bash
git clone https://github.com/sharonnnnrose/ROSE-Flower-Animation.git
```

### 2. Navigate to the Project Folder

```bash
cd ROSE-Flower-Animation
```

### 3. Install Pygame

```bash
python -m pip install pygame-ce
```

### 4. Run the Project

```bash
python rose.py
```

## Controls

| Key | Action |
|---|---|
| SPACE | Restart the blooming animation |
| Close Window | Exit the application |
